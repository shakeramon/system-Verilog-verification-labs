# Module 6 — Object-Oriented Programming for Verification  
Google–NVIDIA Chip Design & Verification Program

This module contains three SystemVerilog verification labs that teach Object-Oriented Programming (OOP) for verification.  
You will build transaction classes, use constraints, apply randomization, and work with class casting — all using professional multi-file package structure.

---

## 📘 Included Labs
### **Lab 1 — OOP & Packages**
Create base and derived transaction classes, organize them across multiple files, and use polymorphism inside a testbench.

### **Lab 2 — Constraints & Randomization**
Add constraints to transaction fields, generate constrained-random stimulus, and use inline constraints (`with`) in a testbench.

### **Lab 3 — Class Casting**
Learn up-casting and down-casting, use `$cast()` safely, and operate on specialized child-class properties.
